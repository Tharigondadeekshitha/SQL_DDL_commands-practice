# Employee Management System

## Description
A Java JDBC application for managing employee records in a MySQL database using JDBC.

## Technologies Used
- Java
- JDBC
- MySQL

## Features
- Add Employee
- View Employees
- Search Employee
- Update Employee
- Delete Employee

## Database Setup
Run the Employee_db.sql file in MySQL Workbench.

## How to Run
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ.
3. Add MySQL Connector JAR.
4. Configure database credentials.
5. Run EmplyeeManagementSystem.java.
